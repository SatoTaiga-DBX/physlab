# 数値積分：手法ごとの精度とエネルギー保存

出典: [設計書 002 単振り子](../design/002-pendulum.md)（実測日 2026-11-23）

## 実測結果

単振り子 θ0 = 120°, L = 1 m, g = 9.81 m/s²、刻み dt = 0.01 s、100 s 間:

| 手法 | 次数 | 相対エネルギー誤差 | 振る舞い |
|---|---|---|---|
| 前進オイラー | 1 | 最終 **+3.21**（321%）| 増え続ける（単調ドリフト） |
| RK4 | 4 | 最大 7.1e-8 | ごく緩やかにドリフト |
| 速度ベルレ | 2 | 最大 1.8e-4 | **有界に振動、ドリフトなし** |

収束次数は調和振動子 y'' = −y で確認済み（刻みを半分にすると誤差は 1/2, 1/16, 1/4 倍）。

## 分かったこと

1. **前進オイラーは振動系に使えない。** 振動するたびに少しずつエネルギーを増やし、
   dt = 0.01 s でも 100 s で実用にならない。振動を扱う題材では選ばない。
2. **短時間・高精度なら RK4。** 今回の条件では絶対誤差はベルレより 3 桁小さい。
3. **ベルレ法はエネルギーが「ずれ続けない」。** 誤差自体は RK4 より大きいが、
   振動はしても一定の範囲に収まる。保存力だけの系の長時間計算（惑星軌道など）向き。
4. **「次数が高い = 長時間で良い」とは限らない。** RK4 は精度が高い代わりに
   エネルギーが一方向にドリフトする。

## 未検証の見通し

- RK4 のドリフトがおよそ 7e-8 / 100 s で線形に進むとすると、ベルレの振幅 1e-4 を
  超えるのは 10⁵ s 級（Python ループでは遅いので未計算）。惑星軌道の題材で実際に確かめたい。
- 速度に依存する力（減衰・磁場中の運動）ではベルレ法はそのままでは使えない。
  必要になったら別手法を設計書で選ぶ。

## 使い分けの目安（暫定）

| 状況 | 第一候補 |
|---|---|
| 短時間で精度が欲しい・速度依存の力がある | RK4 |
| 保存力のみ・長時間（軌道、振動の位相が大事） | 速度ベルレ |
| 手法の比較・教材としての対照 | 前進オイラー |
