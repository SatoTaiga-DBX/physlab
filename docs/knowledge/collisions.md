出典: [設計書 007](../design/007-collisions.md)（実測 2026-11-28）。単位系は無次元（設定は各項に記す）。

## 分かったこと

- **クーロン力だけ力積の近似の誤差が 2 乗**で減る。引力と斥力の偏向が厳密に鏡像（$\alpha$ の奇関数）なので、
  2 次の項が消える。相対誤差は $\theta^2/12$（$\theta=0.088$ で実測 $6.5\times10^{-4}$）。
- 固い球どうしの衝突を実験室系で見た分布は、**崩壊の角度分布の式がそのまま使える**（$k=m_1/m_2$）。
  1 つの関数（`angle_density`）で両方をテストできる。
- 帯電球では、$R<d$ は点電荷と区別できない。$d<R<1.5d$ は $\chi_g=2\arcsin\frac{1}{2R/d-1}$ より大きい角だけがずれる。
  $R=1.4d$ の実測は $70^\circ$〜$80^\circ$ で 1.43 倍、$150^\circ$〜$160^\circ$ で 0.11 倍。

## ハマったこと

| 症状 | 原因 | 対処 |
|---|---|---|
| 帯電球の最大偏向角が、$R/d$ を大きくしても理論の $1.022\,d/R$ に収束しない（$R/d=3478$ で 2.7% 大きい） | 球の表面をかすめる軌道で、積分区間の分け目（球の表面）の $F$ がほぼ 0 になり、前半の区間が準特異になる | 前半の区間も、端に節点を集める置換で積分する（`application/mechanics/deflection.py`） |
| 崩壊の角度の理論値が $V=v_0$ で NaN | $1-k^2\sin^2\theta$ と $1+k^2\cos2\theta$ の桁落ちで 0/0 | $(1-k^2)+(k\cos\theta)^2$ の形で計算する。上限の角も $k\ge1$ で $\arcsin(1/k)$ |
| 動画の粒子の束の先頭が弧になる | 全部の粒子を、中心から同じ距離の円の上に置いて出発させた | `start_radius=sqrt(X**2 + rho**2)` を粒子ごとに渡して、先頭を $x\approx-X$ にそろえる |
| クーロン**引力**でほぼ正面の軌道（$\rho=10^{-4}d$）の偏向角が $10^{-2}$ rad ずれる | 中心のすぐ近くで鋭く折り返し、求積の節点が足りない | 使わない範囲として docstring に明記（テストと図は $\rho\ge0.1d$）。**直していない** |
| 数える実験の 1 区間が 3.4σ | 乱数の偶然（種 2、3 では最大 2.2σ、1.8σ） | 許容を 4σ にし、テストは別の種を使う |
| 記号表に行を足したら、表が 1 ページに入らず `Overfull \vbox` | `tabularx` はページをまたげない | 章ごとの表に分け、見出しと一緒に `minipage` に入れる |

## 数値の方法

- 軌道の式 $\varphi_0=\int\rho\,du/\sqrt{F(u)}$ は、$u=u_{\max}(1-s^2)$ の置換とガウス・ルジャンドル 120 点で、
  解析解と $10^{-11}$ まで合う。時間積分より速く、多数の $\rho$ をまとめて計算できる。
- 数える実験（20 万個）は、1 個ずつ軌道を積分せず、この求積を $\rho$ の配列に使う。
- 時間積分の初期条件は、有限の距離でも無限遠の $\rho$ に正しく対応するように、残りの角
  $\int_0^{1/R_0}\rho\,du/\sqrt F$ を同じ求積で求めて置く。これでクーロン力のような長距離力でも
  $R_0=15d$ で $3\times10^{-8}$ になる。

## 未検証・やっていないこと

- 薄い箔の中で小さな偏向が何度も重なる分布（多重散乱）は計算していない。
- 中心に回り込む引力（orbiting）は扱っていない。
- 原典（ランダウ＝リフシッツ）との照合はしていない（[著作権の方針](copyright.md)）。
