## 分かったこと

- **離散作用の停留条件は速度ベルレ法そのもの**（位置の形 $q_{k+1}-2q_k+q_{k-1}=\Delta t^2a_k$）。
  勾配の式から $q_{k+1}$ を解いて、ベルレの更新式と相対 $10^{-10}$ で一致することをテストした。
  一様重力では $V$ が 1 次式なので、離散作用の停留点が放物線に**節点上で厳密に**一致する。
- **最急降下法は鞍点では使えない。** $\tau>\pi/\omega$ の調和振動子では $c_1<0$ で作用が下に抜けるため、
  `relax_path` は `ValueError` にした。停留点を探すことと最小点を探すことは別。
- **二重振り子の運動方程式の検査は「壊して失敗する」ことまで確認した。** $\Lagr$ を数値微分して作った
  EL 方程式の残差が 0 になるテストで、$\sin\Delta$ の項の符号を壊すと失敗した。通るだけのテストにしない。
- 速度ベルレ法は、加速度が相対位置だけに依る系では $\bm V$ を足しても更新式の形が変わらないため、
  $K$ と $K'$ の軌道が丸め誤差で一致する（上の表）。

## ハマったこと

- **設計書と実装のずれ**: 設計書 005 の初稿は最急降下法の反復を 4000 回としていたが、「最大のずれ $10^{-6}$ m 未満」には
  足りず（遅い成分の減衰率 $0.9972^{4000}\approx1.5\times10^{-5}$）、8000 回が必要だった。設計書を直した。
- **テストの許容**: $S(\varepsilon)-S_*$ が 0 付近の値を相対許容で比べると、$\dot q$ の差分近似（`np.gradient`、
  $O(\Delta t^2)$）の誤差で失敗した。許容を「$S$ の変化幅に対する割合（$10^{-5}$）」にした。
- **テストの前提**: 位相平面のエネルギーは $\theta=0,\pm2\pi$ のどれでも 0 になるので、`argmin` は先頭の $-2\pi$ を返す。
  「$\theta=0$ で 0 かつ全体の最小」と書き直した。滞空時間も、時間格子の最終点（1.427 s）と厳密値（1.4271 s）は一致しない。
- **matplotlib の mathtext**: `\frac12` は解釈できない（`\frac{1}{2}`）。通常の文字列に `\theta` と書くと `\t` がタブになり、
  凡例が「heta」と出た。mathtext は raw 文字列（`r"$\theta$"`）で書く。
- **図の読みやすさ**（PDF を目視して気づいた）: 作用を symlog 軸に描くと読めない → 超過分 $S_d-S_*$ の対数軸。
  凡例・注記が曲線に重なる → y 軸の上に余白を作って凡例を置く、注記には白地をつける。
  補助線の注記は、近い格子点の値でなく**ちょうどの値**（30°、120°）を格子に含めて出す。
