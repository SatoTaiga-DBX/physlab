# 著作権：参考書をもとに教科書を書くとき（調査と方針）

調査日: 2026-11-26。**法律の専門家の見解ではない。** 一次情報を読んで、このリポジトリでの判断を整理したもの。
このリポジトリは公開しているので、章を足すたびにここの方針で点検する。

## 確認した一次情報

| 内容 | 出典 |
|---|---|
| 著作物は「思想又は感情を創作的に表現したもの」（2 条 1 項 1 号）。翻訳・翻案の権利は著作者にある（27 条） | [著作権法の条文（CRIC）](https://www.cric.or.jp/db/domestic/a1_index.html) |
| 公表された著作物は引用できる。公正な慣行に合い、目的上正当な範囲内であること（32 条 1 項）。出所を明示する（48 条） | 同上 |
| 保護期間は著作者の死後 70 年。共同著作物は最後に死亡した著作者の死後（51 条） | 同上 |
| 翻案とは、表現上の本質的な特徴を保ちつつ別の著作物を作る行為。**表現でない部分（アイデア・事実）や創作性のない部分が同じだけなら翻案ではない** | [最高裁 平成 13 年 6 月 28 日（江差追分事件）](https://www.courts.go.jp/hanrei/52267/detail7/index.html) |
| 数学の著作物で示した**命題の解明過程**と、その説明に使う**方程式**は保護を受けない。解明過程の**表現形式**に創作性があれば、それは別 | [大阪高裁 平成 6 年 2 月 25 日](https://www.courts.go.jp/hanrei/13889/detail7/index.html) |

注意:

- 大阪高裁の事件は数学の論文である。物理の教科書に当てはめるのは**類推**。
- 「著作権法 10 条が学説や理論を保護しないと定めている」という説明を調査中に見かけたが、**条文にそのような規定はない**。
  保護されないのは、2 条の定義（創作的な表現）の解釈と、上の判例から。

## このリポジトリでの判断

| 要素 | 扱い |
|---|---|
| 物理法則・事実、式、導出の筋道 | 書いてよい。参考にした文献は示す |
| 参考書の文章（原文、翻訳、文を追いかけた言い換え） | **写さない**。翻案になり得る |
| 参考書の図 | 写さない・なぞらない。自分のコードで作る |
| 参考書の問題と解答 | **載せない**。演習は題材・数値とも独自に作る |
| 節の見出し（「エネルギー」「運動量」などの用語）と順序 | 一般的な用語と物理の論理の順で、リスクは低いと判断。ただし本文の構成は自分で決める |
| 書名・節番号の言及 | 出典の表示として行う。公式の解説書と誤解させない |
| 原文を引く必要がある場合 | 引用の条件（区別できる、本文が主、必要な範囲、出所の明示）を満たす |

ランダウ（1968 年没）とリフシッツ（1985 年没）の原著は、**保護期間内**として扱う。

## 公開済みの内容の点検（2026-11-26）

- 第 3 章に、引用符で参考書の文章を示した箇所はない。図はすべて本プロジェクトのコード
  （matplotlib と TikZ）で作成した。演習は独自に作った。
- 二重振り子のような、多くの教科書で扱う定番の題材は参考書にも出てくる可能性が高い。
  題材そのものは保護されないが、説明と式の展開は自分たちで書いた。
- 直したこと: 部の題を「〜に沿って」から「〜を参考にした学習ノート」へ。序文「この本について」を追加。
  第 3 章の注記の「筆者が自分の言葉で」を、実態（AI の支援で書き下ろし、原典と照合していない）に合わせた。
- **未確認**: 原典・日本語版との照合はしていない（手元にない）。AI が書いた文章が、学習した文章に
  偶然似る可能性は排除できない。**原典を持っている人が読み比べ**、似た文があれば書き直す。

## 章を書くときの手順

1. 構成は自分で決める（問い → 実験 → 導出 → 分かったこと）。参考書を開いたまま文を追って書かない。
2. 図と数値は自分のシミュレーションで作る。
3. 演習は独自に作る。参考書の問題を言い換えない。
4. 節の見出しに「対応: …§N」を示し、`bibliography.tex` に書誌を載せる。
5. push の前に確認する: 原文を貼っていないか、図・問題を写していないか、出典があるか、個人情報がないか。
6. 判断に迷うものは、載せずに相談する。
