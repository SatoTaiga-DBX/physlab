## 読み方

1. 各章の「学習目標」を読み、前提の章を確認する。
2. 本文は**式を自分で導出しながら**読む（途中式を省略しない書き方にしてある）。
3. 「シミュレーションで確かめる」のコマンドを実際に動かし、動画と数値を見る。
4. 演習を解いてから、折りたたまれた解答を開く。

## 章の書き方（新しい章を足すとき）

[_template.md](_template.md) をコピーして `NN-トピック/MM-名前.md` に置く。章は次の順に書く。

| 節 | 内容 |
|---|---|
| 学習目標 / 前提 | この章で何ができるようになるか。先に読む章 |
| 導入 | 何が不思議か、なぜ知りたいか（直観から入る） |
| 本論 | 設定 → 方程式 → 解く → 結果の意味。**導出は飛ばさない** |
| シミュレーションで確かめる | 実行コマンド、動画の見方、**実測した数値**と理論値の比較 |
| 演習 | 基礎・応用・シミュレーション課題。解答は `<details>` で折りたたむ |
| まとめ / 発展 | 要点 3〜5 個。次に学ぶこと |
| 対応するファイル | 設計書・コード・テスト・知見へのリンク |

ルール:

- 数値は**実際に計算して**から書く（暗算や記憶で書かない）。理論値と実測値は区別する。
- 他の資料と同じ記号を使う（下の記号表）。
- 設計書（何をどう作るか）や知見（実装して分かったこと）の内容は繰り返さず、リンクで結ぶ。

## 記号表

| 記号 | 意味 | 単位 |
|---|---|---|
| $t$ | 時間 | s |
| $h$（コード上は `dt`） | 時間刻み | s |
| $g$ | 重力加速度（9.81） | m/s² |
| $L$ | 振り子の長さ | m |
| $\theta$ | 鉛直下向きからの角度 | rad |
| $\omega = \dot\theta$ | 角速度 | rad/s |
| $\omega_0 = \sqrt{g/L}$ | 小角近似の角振動数 | rad/s |
| $T_0 = 2\pi/\omega_0$ | 小角近似の周期 | s |
| $E$ | 力学的エネルギー（単位質量あたりで書くことが多い） | J（または J/kg） |

記号の上のドット $\dot{x}$ は時間微分 $dx/dt$、ドット 2 つ $\ddot{x}$ は 2 階微分 $d^2x/dt^2$。
